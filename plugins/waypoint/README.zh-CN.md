# WayPoint

[English](README.md) | 简体中文

WayPoint 是一个 Claude Code 插件, 提供一组工作流技能.

## 技能列表

| 技能             | 命令                       | 说明                              | 状态   |
| ---------------- | -------------------------- | --------------------------------- | ------ |
| `commit-message` | `/waypoint:commit-message` | 根据当前工作区的改动生成提交消息. | 开发中 |
