# WayPoint

English | [简体中文](README.zh-CN.md)

WayPoint is a Claude Code plugin that bundles workflow skills.

## Skills

| Skill            | Command                    | Description                                                 | Status         |
| ---------------- | -------------------------- | ----------------------------------------------------------- | -------------- |
| `commit-message` | `/waypoint:commit-message` | Drafts a commit message from the current workspace changes. | In development |
