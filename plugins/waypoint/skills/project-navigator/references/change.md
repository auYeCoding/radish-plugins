# 变更, 收尾与恢复

## 需求变更

用户提出新的需求, 或要改已确认的需求时:

1. 先弄清楚变更的内容与原因, 说明它影响哪些已完成与未完成的切片.
2. 有切片正在进行时, 先把它做完或放弃 (`slice drop`), 再改路线. 只影响当前切片的小调整, 按 `ref slice-loop` 的 "中途交回" 改计划并运行 `slice replan`.
3. 用户确认后:
   - 用 Edit 更新 `.navigator/requirements.md`.
   - 用 `roadmap --from <草稿>` 更新路线: 还没有开始的切片可以改名, 调整或去掉; 已经开始的切片带上 `id` 原样保留.
   - 用 `decision add --from <草稿>` 记一条决策: 决定了什么, 为什么, 放弃了什么; 推翻了以前的决策时写 `supersedes`.
4. 用户只是随口一提, 还没有决定要做时, 记进 `.navigator/backlog.md`, 不改路线.

## 收尾

全部里程完成后:

1. 向用户说明成果: 对照需求文件的 "必须要做" 逐条说明; 列出接受了现状的未验证标准, 被放弃的切片, 以及待办中还留着的事.
2. 用户确认后运行 `project-navigator finish`, 按输出提交.
3. 收尾之后用户还有新的工作时, 按上方 "需求变更" 更新需求, 用 `roadmap` 追加里程即可继续.

## 恢复进度

- 新会话调用技能后, "当前状态" 给出位置与下一动作, 照做即可. 需要上下文时读需求文件, 路线视图与进行中的切片文件, 不要重新规划.
- 上下文压缩后, hook 会注入位置与下一动作; 拿不准时运行 `status`.
- 切片在实现中而实现子代理已经不在了 (例如上一个会话已关闭): 运行 `brief exec` 重新派出, 新的子代理靠切片文件的 "中途记录" 与工作区中已有的改动接着做.
- 切片在验收中而验收段还没有写: 运行 `brief review` 重新派出验收子代理.

## 出错时

| 情况                                  | 做法                                                                                                         |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 命令输出 "脚本错误"                   | 按错误信息改; 信息中写了要运行的命令时照做                                                                   |
| `slice review` 说计划段被改动         | 是你按用户的回答改的: 运行 `slice replan`; 不是: 用 `git diff` 查看, 恢复后再送验                            |
| 写文件被守卫拒绝                      | 按拒绝理由调整; 编排会话要改业务文件时, 排进切片                                                             |
| 进入时说记录由旧版本写入              | 本版本不读取旧记录: 用户同意后运行 `init --archive`, 旧的 `.navigator/` 改名为 `.navigator-1.x/`, 再重新立项 |
| 进入时说记录会被 Git 忽略             | 把输出中的忽略规则告诉用户, 用户改好后重新调用技能                                                           |
| 状态与实际对不上 (例如用户回退了提交) | 运行 `check`, 把结果与你看到的情况告诉用户, 由用户决定以哪边为准                                             |
| 照着 "下一动作" 做却走不通            | 把运行的命令与原始输出告诉用户, 不绕开, 不修改技能文件                                                       |
