# 写作规则

<!-- 本文件由 scripts/gen-navigator-docs.mjs 生成, 不要直接修改; 请修改规格或 scripts/navigator-docs/ 中的源文件后重新生成. -->

编排会话写的每一条回复与每一份记录文件都遵守本文件. 回复结束时 hook 按同一份规则校验 "问题" 级别的条目, 体检命令 `check` 同时报告 "问题" 与 "提示".

## 朴素中文

- 一句话只说一件事, 结论先行; 不铺垫, 不复述, 不写空话套话.
- 不自造简称: 名词第一次出现时写全称; 新术语先写进术语表 `.navigator/plan/glossary.md`.
- 不打比方, 不用黑话: 直接写事实, 数字与文件路径.
- 不用没有名词的指代: 写 "工单 0007", 不写 "它"; 写 "这个切片", 不写 "这".
- 例子要完整: 写出输入, 操作与结果.
- 一处只讲一个焦点: 一节一个主题, 一段一个意思.
- 不依赖读者记忆: 需要前文信息时, 重写关键内容或给出文件路径.

## 面向注意力障碍与强迫倾向的读者

- 结构固定: 标题, 键名, 选项与总结的位置每次都一样, 读者不用重新寻找.
- 信息分块: 段落, 列表与嵌套都有上限, 见下方规则表.
- 对齐整齐: 编号与计数按固定位数补零, 同一组选项字数一致, 表格源码按显示宽度对齐.
- 下一步明确: 每条回复都以选项块结尾, 选项之外不留开放问题.

## 规则表

| 类别     | 级别 | 规则                                                     |
| -------- | ---- | -------------------------------------------------------- |
| 结构不符 | 问题 | 记录文件的标题, 节与键名不符合规格                       |
| 句子过长 | 问题 | 没有标点的片段超过 40 字; 达到 20 字时给出提示           |
| 段落过长 | 问题 | 连续的普通文本超过 4 行                                  |
| 列表过长 | 问题 | 同一层列表超过 7 项                                      |
| 列表过深 | 问题 | 列表嵌套超过 2 层                                        |
| 加粗过多 | 提示 | 一节中加粗超过 3 处                                      |
| 的字过多 | 提示 | 一个片段中 "的" 超过 2 个                                |
| 黑话用词 | 问题 | 使用黑话, 见禁用词                                       |
| 比喻用词 | 问题 | 使用比喻用词, 见禁用词                                   |
| 翻译腔调 | 提示 | 使用翻译腔句式, 见禁用词                                 |
| 指代不明 | 问题 | 句首使用没有名词的指代词, 例如 "它", "这是"              |
| 表格未齐 | 提示 | 表格源码的竖线没有按显示宽度对齐                         |
| 篇幅过长 | 提示 | 回复超过 60 行, 或记录文件超过 200 行 (只追加的记录不限) |

字数的算法: 汉字, 英文单词, 数字, 路径各算 1 字, 行内代码与网址整体算 1 字, 空格与标点不算.

## 禁用词

- 黑话用词: 赋能, 抓手, 闭环, 打通, 沉淀, 颗粒度, 心智, 底层逻辑, 顶层设计, 组合拳, 拉通, 倒逼, 反哺, 护城河, 飞轮, 势能, 赛道, 深耕, 丝滑, 无缝.
- 比喻用词: 就像, 好比, 犹如, 仿佛, 如同, 宛如, 比作, 打个比方.
- 翻译腔调:
  - 去掉 "进行", 直接用后面的动词.
  - 去掉 "作出", 直接用后面的动词.
  - 去掉 "对于...来说", 直接说对象.
  - 把 "在...的情况下" 改为 "如果...".
  - 把 "通过...的方式" 改为 "用...".

## 标点与排版

- 使用英文 (ASCII) 标点, 禁止中文全角标点; 成对符号也用 ASCII 版, 即 `()`, `""`, `''`.
- 每个标点后跟一个空格; 标点位于行尾或文本末尾时不加.
- 标点属于数字, 代码, 标识符, URL 或路径等 "记号" 整体的一部分时不加空格. 例: `v2.1.187`, `file.txt`, `C:\path`, `50%`, `a/b`.
- 成对开合标点按英文惯例: 开符外侧留空格内侧不留, 闭符内侧不留外侧留空格.
